# Image Placeholder Guide

This directory structure is designed for easy image management. Replace these placeholder paths with your actual photography.

## Directory Structure

```
public/images/
├── hero/
│   ├── hero-main.jpg          (Homepage hero - 1920x1080 or larger)
│   └── cta-bg.jpg             (CTA section background)
├── portfolio/
│   ├── portrait-01.jpg        (Portrait photographs)
│   ├── portrait-02.jpg
│   ├── street-01.jpg          (Street photography)
│   ├── street-02.jpg
│   ├── landscape-01.jpg       (Landscape photographs)
│   ├── landscape-02.jpg
│   ├── event-01.jpg           (Event photography)
│   ├── lifestyle-01.jpg       (Lifestyle photography)
│   └── documentary-01.jpg     (Documentary photography)
├── categories/
│   ├── portraits.jpg          (Category cover images)
│   ├── street.jpg
│   ├── events.jpg
│   ├── landscapes.jpg
│   └── lifestyle.jpg
└── stories/
    ├── story-01.jpg           (Story cover images)
    ├── story-02.jpg
    └── story-03.jpg
```

## Image Recommendations

### Hero Images
- Dimensions: 1920x1080 or larger
- Format: JPG or WebP
- Striking, high-impact photography

### Portfolio Images
- Mixed aspect ratios for visual interest
- High quality, well-composed
- Optimized for web (under 500KB each)

### Category Images
- Dimensions: 800x1200 (portrait orientation works well)
- Representative of category style

### Story Images
- Dimensions: 1200x800 (landscape)
- Engaging, story-relevant

## Quick Setup

1. Export your best photographs
2. Rename them to match the structure above
3. Place them in the appropriate folders
4. The site will automatically load them

All images are optimized by Next.js Image component automatically.
